## Folder rules (added 2026-11-09)
- When starting something new (new project, experiment or idea), create a new dedicated folder for it. Never mix it into this or another existing project: if it does not belong in this repo, say so and ask where it should go.
- Keep folders organized: clear names, a README in each project, no loose files in the root.
- Before creating files, check where they belong. If unsure, ask.
